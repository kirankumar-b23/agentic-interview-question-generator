Agentic interview-question workflow

Questor 🎯

Pick a course topic; four cooperating agents read the session material, quest for real, company-attributed interview questions, validate them, and hand a review-ready set to a human for one-click export into the NxtMock portal.

Retrieval sources

📖 Question bank priority 1

Pre-indexed, verified company questions.
TF-IDF~1,500 questions (scikit-learn cosine similarity) over interview_questions.json. Real company attribution.

🌐 Tavily web priority 2

Real company-attributed questions from the open web.
APISearch across 50+ allow-listed domains — Glassdoor, AmbitionBox, Exponent, LeetCode… Company parsed from the URL; unknowns labelled NIAT.

🐙 GitHub repos priority 3

Curated interview-question repositories.
RESTStructured technical questions from a configured repo list — supplements the bank + web.

Knowledge & data

🧠 Session understanding

  • Per-session reading material — session_map.json, exact-keyed to each session, drives accurate outcomes.
  • Knowledge graph — knowledge_graph.json: KPs, sessions, prerequisites (networkx).
  • Course structure — course_structure.json: topic → sessions; also labels runs by topic.

💾 State & persistence

  • SQLite — full runs persisted, so Review & re-export survive restarts and show in History.
  • Learned rules — rejection feedback distilled to sharpen future validation.
  • Runtime controls — model + light/dark theme selectable in the UI; OpenRouter credits shown.
